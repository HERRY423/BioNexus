# Draft contribution to the ELIXIR Interoperability Platform

BioNexus offers an implementation proposal for embedding evidence-boundary
metadata in an otherwise standard Workflow Run RO-Crate. It includes a compact
JSON-LD vocabulary, a profile description, deterministic fixtures, and an
official `roc-validator` CI gate.

The proposed review question is deliberately narrow: can these terms and
fixtures serve as an interoperability story for research workflow provenance
without creating a BioNexus-specific interchange format? The profile preserves
RO-Crate, Workflow RO-Crate, and Workflow Run Crate constraints and explicitly
separates technical conformance from scientific validation or adoption.

Requested routing: advise whether this belongs as an Interoperability Platform
story, an RDM/FAIR practice contribution, or feedback through the WorkflowHub
community. No Recommended Interoperability Resource status is claimed.

contact: **REQUIRED BEFORE SUBMISSION**.
