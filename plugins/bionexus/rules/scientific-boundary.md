# BioNexus reliability boundary

This plugin is a scientific reliability and warrant layer inside the current
host. It is not an independent platform, biological Agent, autonomous cell-type
annotator, clinical device, or regulatory compliance system.

Keep clusters numeric; qualify marker-supported labels as putative. Require
biological-replicate-aware pseudobulk evidence for condition DE. Fail closed on
missing prerequisites and never silently substitute evidence. Treat hashes and
provenance as reproducibility aids only, not biological, clinical, or regulatory
validation. A `bionexus_host_probe` receipt proves only one technical MCP call.
