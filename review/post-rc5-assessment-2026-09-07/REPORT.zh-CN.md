本次阅读实际实现、变更、验证登记、公开 CI、互操作试验、已有论文草稿，并执行针对性软件测试及合成反例。没有修改产品代码、重跑生物学研究、联系外部人员或发布内容。原始反例见 [probe-results.json](probe-results.json)，重现入口见 [reproduce.py](reproduce.py)，验证范围见 [verification.json](verification.json)。

**总判断：这一轮有实质改善。BioNexus 已具备值得开展受控试点的科学可靠性内核；但距离可以被实验室日常信赖、独立维护者共同采用的基础设施，以及由比较实验证明优势的高水平方法论文，仍有明确差距。最大问题是关键入口仍把格式或静态线索提升为科学授权，外部证据与实测使用收益尚未建立。**

| 目标 | 目前能够支持的判断 | 还差的主要证据 |
|---|---|---|
| 顶尖生物学基础设施 | 被动可靠性内核、类型化证据接口、版本与来源治理、标准互操作原型已存在 | 统一授权语义、稳定发行物、真实产物绑定、独立实现者与长期维护共同体 |
| 顶尖实验室使用 | 可以准备限定任务、研究者复核的影子审计试点 | 首次安装与真实数据无作者陪跑；误报/漏报/时间成本；同一结果到具体声明的闭环 |
| SCI 一区方法学论文 | 有方法问题、实现、公共数据案例、负结果与论文草稿 | 明确独特贡献、强基线、未见任务、独立专家标签、消融及真实科研效用 |

这里的距离是证据门槛，不是未经校准的“完成百分比”。JCR Q1 与中科院一区应按目标年度和学科另核；Nature Methods 用作高水平方法论文标准参照，并不等同于所有一区期刊。

## 1. 本轮已经关闭的问题

1. **空输入与样本表不再自动通过。** 无输入返回 `NOT_ASSESSED`；只有六供体、两组样本表返回 `NEEDS_DATA`。已执行方法与建议分析被分开，不再凭空写已完成 NB GLM/Wald/BH。
2. **Scanpy 结构化结果读取修复。** 合成结构化数组保留 IFITM1、STAT1 的完整标识及 p/padj/logFC；AnnData 集成测试通过。初次本地执行卡在 Numba 缓存创建，指定工作区缓存后解决，不能据此归因于科学算法失败。
3. **字符串绕过修复。** `note = 'pseudobulk later'` 不再清除伪重复发现。新实现采用 AST，而非仅凭字符串搜索。
4. **证据索引确实比较 SHA-256。** 当前索引检查通过 30 项；把索引副本的 19 个 source-hash 条目全部改成零，19 项均报哈希不匹配。`--impact` 优先读冻结基线，`real_host_certified` 已收回到 false。
5. **LIMS 缩小试点范围。** 缺少 well/value/unit/sample_id 的测量被拒绝；模拟调用 live export 得到 `PILOT_EXCLUDED`，未到达 `requests.post`。这是有效隔离，不代表真实 LIMS 集成已验收。

五个相关测试文件共 64 个不同测试全部通过，分两组运行；环境为本地 Python 3.13.9，不代替支持矩阵和发行物验证。

## 2. 距离顶尖基础设施：缺少可依赖的统一事实与授权链

### 当前最重要的四个剩余问题

**P0：结果列名仍可以兑换群体推断授权。**

最小输入是一个未经任何模型计算的表：`gene=G1, pvalue=0.01, padj=0.02`，加六供体、两组各三人的样本表。结果是 `NEEDS_DATA`；仅增加 `baseMean=100` 一列，立刻变成 `ROBUST_PASS / ROBUST_POPULATION`。

根因在 `src/bionexus/de_audit.py:1453` 与 `:1500`：只要出现 baseMean/lfcSE/logCPM/LR 等任一标志，就把统计单位推断成 donor-level，并把它作为通过条件。模型、设计矩阵、contrast、结果对应的样本、模型收敛都未验证。DESeq2 风格的列也不能说明其输入行就是独立供体。

同样输入把 p/padj 改为 -0.1/-0.2 仍 `ROBUST_PASS`。`src/bionexus/de_audit.py:1183` 主要检查 adjusted-p 列存在，尚未充分检查数值域、可解析性与缺失覆盖。

**建议：** 保留“格式识别”能力，但赋予它格式层含义；群体授权需要来自对应产物的统计单位、样本/设计/contrast、输入矩阵身份与拟合状态证据。原始数据不必强制重复上载，可接受实验室本地运行器产生的可检查、绑定具体产物的记录。不同证据来源不能拥有相同权限。

**P0/P1：静态 AST 仍把看见调用当成数据流正确。**

以下代码都能消除 BFA-001，即使真正执行的 DE 仍用原始细胞对象：

```python
if False:
    pseudobulk_aggregate(adata)
sc.tl.rank_genes_groups(adata, groupby='condition')
```

另外，`metadata.groupby('donor').size()` 或 `pseudobulk_aggregate(other_adata)` 也能起同样作用。这里只解析这些文本，未执行任何分析。

`src/bionexus/analysis_audit.py:295` 的 visitor 不证明分支可达或聚合输出流入 DE。正向测试 `tests/unit/test_analysis_audit.py:58` 还把 `pb=...` 后继续对 `adata` 做 DE 视为不应报错，说明部分测试已固化宽松假设。

**建议：** 静态扫描负责提出线索、定位风险；不能据此证明实际执行。可先实现受限的对象/产物绑定，再覆盖不可达分支、未使用聚合结果、对象替换、旧结果复用，而无需建设通用程序验证器。

**P1：新 DE 入口与声明审计尚未统一。**

`claim_text` 被传入 `_determine_claim_boundary`（`:1509`），但没有参与判断。将同一表的声明换成“G1 causes disease and is a proven therapeutic target”，结果仍与无声明输入相同。报告仍有通用禁止因果外推的文字，因此不能称它明确授予了因果结论；准确的问题是：没有对这条越界声明给出独立、定向的判定。

另一反例：明确声明“FDR 后无显著基因”，仍因 101 个 raw p<0.05、零个 padj<0.05 被标为 `NEEDS_REVISION/BFA-003b`。是否选择性报告应检查实际声明，零显著结果本身不是方法失败。

**建议：** 新入口复用已有 typed claim 与 warrant 引擎，分别输出产物质量、已验证分析事实、具体声明授权。将缺证据、格式无效、科学不支持、诚实负结果区分开。尊重人类科学裁决，并保留裁决依据；复核签字不能创造缺失证据。

**P1：索引语义校验采用子串匹配。**

`src/bionexus/evidence_index.py:854` 用互为子串允许 verdict 等价。将索引副本中的 GSE96583 verdict 从 PASS 改为 NOT_PASS，底层报告仍 PASS，校验竟通过。哈希修复是真实的，但语义一致性仍需严格枚举和按报告类型声明的映射；未知状态、无状态、矛盾状态不能默认为兼容。

## 3. 距离顶尖实验室产品：需要证明净收益与低接入成本

有真实工作价值的入口已经出现：对完成的单细胞 DE 给出问题、定位、最小修复、可陈述范围和负责人裁决。首个购买/采用理由应具体到“减少组会、投稿和结果共享前的无依据外推，并节省复核时间”。

真实数据证据不能忽略：GSE96583 有 13,487 singlets、8 donors 的实际 pseudobulk；annotation 外部参考案例记录 148,297 mapped cells；空间案例使用真实 Xenium 文件。它们不是纯玩具，但证据边界仍然不同：

- GSE96583 独立验证记录的锁定 endpoint p=0.05859375，阈值 0.05，保留 `independent_biological_validation=not_supported`。
- Azimuth 参考标签可用于参考一致性，不是独立盲法生物学真值；跨组织转移和正式校准仍未建立。
- tiny Xenium 的报告明确限制为格式与技术接受，不支持组织泛化或生物学有效性。
- IVN 中已验证外部实验室研究、非作者评审、校准 freezes 均为 0；没有 APPROVED 经验校准 profile。

建议先做单一产品承诺：**多供体单细胞 DE 的影子审计**。保持被动插件，优先接收既有产物，输出研究者可复核的报告。LIMS、诊疗、广泛模态认证继续留在其当前未建立范围。

首轮选择两家外部实验室，每家约 10 个历史分析作为接入与误报发现起点；这是建议的试点规模，不是论文充分样本量。覆盖正确分析、真实错误、证据不足、合法负结果、有效配对/混合模型等例外。锁定审阅规则，专家先看原始产物再看 BioNexus，保存分歧，不把不确定标签强迫成真假。

试点至少测五件事：

1. 新用户从发行包独立安装，到读懂第一份有效报告的时间和所需作者帮助次数。
2. 能定位到具体样本/对象/contrast/声明的发现比例，而非通用警告数量。
3. 对正确分析的误报、对错误外推的漏报，以及对证据不足的恰当保留。
4. 科学家复核与修复用时，建议是否真正可执行。
5. 复核后是否改变了错误声明或无效后续实验决策；记录自然复用意愿。

试点先用只读建议模式，不以自动批准替代 PI/统计学家。通用规则应折叠展示，真正需要科学判断的少数问题才进入裁决页；保持完整机器记录供追溯。

**距离判断：受控共同开发试点可以准备，常规托付还不能宣称。** 缺口可以由一个小而严谨的跨实验室项目检验，而不必先做完整平台、完善所有治理机构或连接所有数据库。

## 4. 距离一区方法学论文：核心缺口是新方法的增量效用

已有论文、图、补充材料和 claim-evidence matrix，写作框架并非从零开始。现有本地 `manuscript/biorxiv_submission_2026-08-22` 仍含旧 61/61、7/14 等快照；正文已加入真实 CITE-seq，而摘要/limitations 仍泛称 annotation/spatial synthetic，矩阵还写 public flagship skipped。可以发表历史快照，但所有图表和状态必须一致绑定同一个研究版本，不能混合不同代证据。

诚实披露缺陷是优势，却不能代替方法贡献。Nature Methods Article 明确要求新方法/工具及足以支持性能、可复现性、一般适用性和发现新生物学潜力的强验证：[官方稿件类型](https://www.nature.com/nmeth/content)。这比“测试通过、格式规范、更多功能”要求更高。

新颖性也必须更新定位。已有研究关注生物学 Agent 的鲁棒性与 outcome validity，例如 [BioAgent Bench，2026 预印本](https://arxiv.org/abs/2601.21800)；[LifeSciBench](https://openai.com/index/introducing-life-sci-bench/)也已评价证据处理、论证、限制与科研实用性。因此不能再把整个领域描述成仅关注任务完成或最终答案。此次检索不构成穷尽性新颖性证明。

BioNexus 更值得检验的贡献是：**在相同模型与工具条件下，基于绑定执行产物的类型化证据约束，是否降低未获证据支持的生物学声明，同时保留正确发现并减少专家复核成本。**

这一定义保留 BioNexus 的被动角色，也使证据债务、claim IR、来源约束和人类裁决围绕一个可测问题组织起来。

推荐比较设计：

| 组别 | 用来回答的问题 |
|---|---|
| 原始 host/agent | 基线的错误外推与任务完成情况 |
| 相同 host + 科学检查清单 | 增益是否只来自额外提醒 |
| 相同 host + LLM reviewer | 确定性约束是否优于再一次模型复核 |
| 相同 host + BioNexus | 完整方法的增量收益 |
| 去掉产物绑定/类型化声明/校准约束的消融 | 哪个机制贡献收益，哪个只增加成本 |

比较保持模型版本、任务、工具/数据权限和成本条件可比。可采用两种互补设计：对相同冻结分析输出进行配对审计，隔离审计器本身的效果；再在前瞻工作流中测“提示—修改—复核”的实际收益。不要把不同 host 架构和模型能力混入审计器效应。

主要终点推荐为：在相同有效声明覆盖率或任务成功率下，未获支持声明比例的变化。并列报告误阻断、漏报、放弃率、净复核用时、推理/计算成本。没有校准概率输出时，不要把 ROBUST 等等级直接当正确率或画概率校准图。

语料须包含合法例外和难负例，保留从未用于开发的研究/实验室；按研究、供体或实验室划分与估计不确定性，不能把同一数据集的上千个基因声明当上千个独立研究。两名独立领域专家先盲审，第三人处理分歧，并保留 unresolved。正式样本量由试点误差率、预期最小重要差异及组内相关性决定。

规则不能只重复“应该做 pseudobulk”：已有工作已系统研究独立生物学重复与 DE 假发现，[Squair et al. 2021](https://www.nature.com/articles/s41467-021-25960-2)。新论文要证明对真实分析与语言声明的约束何时可靠、何时失效、相对朴素方法有何额外价值。

最后补一个结果驱动的案例：BioNexus 改变了哪个错误外推、为何改变、独立复核或重分析如何确认、是否节省了后续验证。若论文主张改善声明可靠性，不必为了“一区”机械增加湿实验；若主张发现因果机制或治疗靶点，就必须补该主张要求的生物学验证。

**距离判断：具备有价值的方法学研究起点，但当前还没有足以证明一区方法论文竞争力的比较证据。** 高水平方法论文不必等到基础设施被广泛采用，但需要一个已被严格证实的增量贡献。

## 5. 下一步顺序与退出条件

| 顺序 | 具体交付 | 何时算完成 |
|---|---|---|
| 1 | 关闭本报告的格式授权、无效统计量、静态数据流、声明未绑定和 verdict 子串问题 | 旧反例及同类变体不再得到不当升级；合法负结果和有效例外不过度阻断 |
| 2 | 修复 core/scientific 测试边界，冻结新发行物 | 支持矩阵全绿；干净安装同一 wheel/插件能复现；版本、报告和产物一致 |
| 3 | 两家外部实验室、单细胞 DE 影子审计试点 | 保留完整独立评审、误报漏报、接入和时间记录；证明存在可复用净收益 |
| 4 | 冻结方法、测试集和比较分析计划，执行论文级实验 | 强基线、消融、未见研究和专家评审共同支持预先定义的收益；负结果原样保留 |
| 5 | 根据实测胜出点重写论文及对外贡献 | 一个清晰贡献、所有主要数字能由冻结包重现、每个主张对应适当证据 |

下一轮资源应优先投入“从证据产物到具体声明的闭环”和独立使用证据。暂停扩展同作者协议数量、广泛领域承诺和大平台功能。让一条最有价值的链条被其他实验室真正使用，才会同时缩短产品、基础设施与论文三条路径。
