# Declared selection-history scenarios

Run `python examples/de-selection/build_examples.py --out NEW_DIRECTORY` from the repository.
The writer refuses an existing output directory. Read its `COMPARISON.md` and per-case reports.

These are **synthetic counterfactual event histories**, not captured researcher activity,
preregistrations, independent reviews, new fitted analyses or scientific validation.
All cases bind the same final DE result and claim contract. The test isolates how
reported choices affect permitted interpretation without changing numerical facts.

See [the input contract and host integration guide](../../docs/de-selection-history.zh-CN.md).
