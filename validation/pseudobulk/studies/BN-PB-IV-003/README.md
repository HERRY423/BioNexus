# BN-PB-IV-003 status

This successor study is preregistered but not yet unblinded or biologically claim-ready.

It requires a full or deterministic natural-proportion Parse IFN-beta/PBS extraction across all 12 donors, an independent 6-hour IFN-beta PBMC holdout, exactly 4,095 non-identity paired sign flips, and a signed blinded analysis from an independent biostatistician. The public balanced Parse 10K/100K exports do not satisfy the C02 sampling gate.

BN-PB-IV-002 remains permanently frozen as a negative result (`p = 0.05859375`). BN-PB-IV-003 is a new study and is not a post-hoc extension of the predecessor permutation test.
