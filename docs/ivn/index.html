Request for Validation (RFV) — How to Fill the Ledger

Clear, standardized protocols for external contributors to submit evidence and expand the moat

An Open Call to the Global Biomedical Research Community

BioNexus adheres to a strict fail-closed, trust-no-one scientific epistemology. We believe benchmark claims without cryptographic provenance and external replication are scientific liabilities. We provide four distinct participation tracks for researchers worldwide:

Track 01
Independent Dataset Provider
Contribute public or prospective benchmark datasets (e.g. GEO, Zenodo, BioStudies). Must provide raw counts, donor metadata, and orthogonal ground truth (qPCR, FACS, pathology annotations).
  • Fill INDEPENDENT_DATASET.template.json
  • Lock preregistration & compute artifact SHA-256
  • Submit via GitHub Issue or Pull Request
Register Dataset →
Track 02
External Laboratory Benchmark
Execute BioNexus canonical pipelines in your own institutional environment (Cloud, HPC, or local cluster). Sign an independence declaration and submit the generated run capsule.
  • Run canonical benchmark pipeline
  • Sign EXTERNAL_LAB_STUDY.template.json
  • Record execution capsule SHA-256
Submit Lab Replication →
Track 03
Blinded Non-Author Peer Review
Biostatisticians and domain scientists absent from the author roster conduct blinded audits of benchmark studies and issue signed scientific attestations (ENDORSED / CHALLENGED).
  • Audit study preregistrations and code
  • Issue verdict via INDEPENDENT_REVIEW.template.json
  • Submit attestation ID and review hash
Submit Review Attestation →
Track 04
Calibration Profile Freeze
Freeze empirical warrant thresholds against held-out biological partitions (cross-technology, cross-disease) to authorize diagnostic warrants in new contexts.
  • Ensure profile review status is APPROVED
  • Bind held-out partition fingerprints
  • Run bionexus ivn freeze-profile
View Freeze Guide →
